# StudyHub AI

## Visão Geral

StudyHub AI é uma plataforma de estudos com inteligência artificial que reúne ferramentas de produtividade, aprendizagem e gamificação em um único ambiente.

## Problema

Os estudantes utilizam diversos aplicativos separados para estudar, revisar conteúdos, fazer perguntas para IA, utilizar flashcards, controlar tempo de estudo e acompanhar seu progresso.

O objetivo é centralizar essas funcionalidades em uma única plataforma.

---

# Objetivos

- Aumentar a produtividade.
- Melhorar a retenção do conhecimento.
- Incentivar a consistência dos estudos.
- Utilizar IA como tutor inteligente.
- Fornecer métricas detalhadas da evolução do aluno.

---

# Funcionalidades

## Autenticação

### Requisitos

- Cadastro
- Login
- Recuperação de senha
- Login com Google
- Login com GitHub

### Critérios de Aceitação

- O usuário deve conseguir criar uma conta.
- O usuário deve permanecer autenticado.
- Deve ser possível recuperar a senha.

---

## Dashboard

### Funcionalidades

- Horas estudadas
- Tempo diário
- Tempo semanal
- Tempo mensal
- Evolução dos estudos
- Gráficos
- Metas

### Critérios de Aceitação

- Atualização automática após cada sessão de estudo.
- Exibição de métricas em tempo real.

---

## Pomodoro

### Funcionalidades

- Sessão de foco
- Pausa curta
- Pausa longa
- Histórico de sessões

### Critérios de Aceitação

- Registrar automaticamente o tempo estudado.
- Atualizar o dashboard.
