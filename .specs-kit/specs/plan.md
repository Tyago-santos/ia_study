# Plano — StudyHub AI

## Objetivo

Este documento descreve como a aplicação deve funcionar do ponto de vista do usuário, servindo como guia durante o desenvolvimento.

---

# Módulos

- Autenticação
- Dashboard
- Pomodoro
- IA
- Flashcards
- Quiz
- Resumos
- Biblioteca
- Perfil
- Configurações
- Estatísticas
- Gamificação

---

# Fluxo do Usuário

## Primeiro acesso

1. Criar conta
2. Configurar perfil
3. Escolher objetivo de estudo
4. Criar primeira matéria
5. Iniciar primeiro Pomodoro

---

## Estudando

Usuário escolhe uma matéria

↓

Inicia um Pomodoro

↓

Faz anotações

↓

Pergunta para IA

↓

Gera flashcards

↓

Resolve um quiz

↓

Visualiza estatísticas

---

# Dashboard

## Deve mostrar

- Horas estudadas hoje
- Horas da semana
- Horas do mês
- Calendário estilo GitHub
- Sequência de estudos
- Metas
- Últimas atividades
- Evolução por matéria

---

# Flashcards

## Funcionalidades

- Criar
- Editar
- Excluir
- Organizar por matéria
- Revisar
- Gerar por IA

---

# Quiz

## Funcionalidades

- Criar manualmente
- Gerar pela IA
- Resolver
- Ver correção
- Histórico de tentativas

# IA

- responder dúvidas
- explicar conceitos
- criar exercícios
- gerar flashcards
- gerar quiz
- resumir textos
- corrigir respostas
- montar plano de estudos
